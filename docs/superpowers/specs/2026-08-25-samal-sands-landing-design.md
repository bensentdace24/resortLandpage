# Samal Sands & Shores Landing Page Design

Build a responsive React presentation mockup for Samal Sands & Shores. The page uses a tropical editorial direction: deep marine ink, sunlit coral, lagoon cyan, mango, and soft sand. Aurora color fields and organic image compositions create atmosphere without obscuring content.

The first viewport combines a concise destination promise, direct inquiry CTA, visual proof, and a compact availability preview. Subsequent sections cover the resort experience, accommodation options, an editable trip planner, illustrative traveler notes, location/contact details, and a final inquiry close.

All booking results are estimates only and do not submit reservations. Publicly reported amenities and contact details are presented carefully; rates and testimonials are clearly identified as sample or illustrative. The interface supports keyboard navigation, reduced motion, responsive layouts, and readable contrast.

Implementation uses React, Vite, plain CSS variables, Lucide icons, and Vitest/Testing Library. Content lives in focused data objects and components so the mockup can be quickly revised after owner feedback.
